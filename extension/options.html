InjectGuard options

1. Pair with the desktop engine (recommended)

The extension works on its own with in-browser checks. Pairing adds the full engine, the optional local AI check, scanning of linked PDFs and Office files, and one shared history in the desktop app. Everything stays on this computer (127.0.0.1).

  1. Install and open the InjectGuard desktop app (or run injectguard service).
  2. In the app choose Tools → Copy Extension Pairing Token (or run injectguard token).
  3. Paste it below and press Save & test.

3. Trusted sites

One host name per line (for example docs.google.com). Trusted sites are not scanned automatically; you can still scan them from the toolbar button.

4. Alert history

Keyboard: Alt+Shift+I open · Alt+Shift+S re-scan · Alt+Shift+H reveal hidden text (change at chrome://extensions/shortcuts).
